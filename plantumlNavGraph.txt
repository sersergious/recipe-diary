```plantuml
@startuml
[*] --> Browse

state Browse : Recipe list (start destination)
state Favorites : Favorites list
state Detail : Recipe detail (recipeId arg)

state CreateGraph {
  [*] --> CreateDetails
  state CreateDetails : Step 1 — name + category
  state CreateIngredients : Step 2 — ingredients
  state CreateSteps : Step 3 — instructions
  CreateDetails --> CreateIngredients : Next
  CreateIngredients --> CreateSteps : Next
  CreateSteps --> [*] : Save
}

Browse --> Detail : tap recipe
Browse --> CreateGraph : tap Add tab
Browse --> Favorites : tap Favorites tab
Favorites --> Detail : tap recipe
Favorites --> Browse : tap Browse tab
Detail --> Browse : back / up
CreateGraph --> Browse : Save / cancel
@enduml
```

| Screen | Function |
|---|---|
| Browse | Lists all recipes grouped by category; entry point to detail and create flow |
| Favorites | Lists only recipes the user has favorited; navigates to detail |
| Detail | Shows a single recipe; supports favorite toggle |
| CreateDetails (Step 1) | Captures recipe name and category |
| CreateIngredients (Step 2) | Captures ingredients list |
| CreateSteps (Step 3) | Captures instructions; saves recipe and exits the nested graph |
